# SwiggyWala.com website setup

Responsive simple-PHP travel website for SwiggyWala.com.

## Contact details

- Booking and WhatsApp number: `9929797091`
- Update business address in `config.php`
- Email: `info@swiggywala.com`

## Hosting

Upload the repository contents to Hostinger `public_html` and select PHP 8.1 or newer. Enable SSL for the domain.

The contact form currently validates form data and displays a confirmation. Connect an SMTP or transactional mail service before launch for email delivery.

## Images

The included `SwiggyWala-Image-Generation-Plan.xlsx` lists every required WebP image, exact filename, folder, size, prompt and SEO alt text.

## SEO launch checklist

- Add all planned WebP images

- Submit `sitemap.xml`
- Add the final address and social profile links
